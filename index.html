Privacy & Trust

This prototype stores workspace information only in this browser using local storage. Recruiter-email text is reviewed only while that page is open and is not included in workspace exports. The prototype has no server, account-recovery system, payment system, external connector, background automation, or autonomous application feature.

Do not enter sensitive information: Do not use passwords, authentication codes, Social Security numbers, financial account details, medical information, private customer information, or confidential employer data in this prototype.

Important: Clearing browser storage can erase local data. Use Export to create a portable JSON backup.
