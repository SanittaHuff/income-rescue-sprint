# Captain User Testing — Coach Mode Plan

Status: Prepared, not yet executed.

## Purpose
Validate that the private MVP is understandable, operable, accessible, and trustworthy for its intended user before private-MVP certification.

## Session Rules
- One screen and one task at a time.
- Chief states **CAPTAIN ACTION REQUIRED** before every user action.
- Captain may stop, pause, ask for explanation, or report confusion at any point.
- No test result is treated as user error; confusion is a product finding.
- Read Aloud compatibility is checked before content-heavy tasks.

## Test Sequence
1. Evidence entry and source identification.
2. Confidence selection and safe handling of missing evidence.
3. Duplicate-certification prevention.
4. Resume assembly from certified components only.
5. Job-match review and evidence-gap language.
6. RTF download and output review.
7. Integrity-checked backup download and restore.
8. Privacy reset with destructive-action confirmation.
9. Keyboard-only navigation, 200% zoom, Read Aloud, and focus visibility.

## Acceptance Signals
- Captain understands the next action without guessing.
- The interface never implies that a job description proves experience.
- Duplicate certification does not create duplicate components or audit claims.
- Work is preserved when verification is incomplete.
- Captain can recover, export, and delete local data intentionally.
- Required actions are explicit and separated from informational text.

## Exit Criteria
All critical findings repaired and retested; noncritical findings documented with owner and disposition.
