# Captain Review Guide — Visible MVP

This guide is for reviewing the product as a real user, not as a developer.

## Review mission

Confirm that the product is understandable, useful, trustworthy, and visibly connected to the Income Rescue Sprint mission.

## Ten-minute review path

1. Open the Overview and read the primary promise.
2. Open **Data & Settings** and enter a name and target role.
3. Add one **Experience Evidence** record.
4. Verify the evidence using the explicit confirmation step.
5. Open **Resume Readiness** and draft one component from that evidence.
6. Approve the exact wording.
7. Add one **Opportunity** with fit, arrangement, urgency, evidence strength, and pay alignment.
8. Review the calculated priority score.
9. Open **Next Best Action** and confirm the recommendation is sensible.
10. Export the workspace, then confirm a JSON file downloads.

## Acceptance questions

- Can a first-time user understand what the product does within one minute?
- Does every factual resume claim trace back to verified evidence?
- Can the user edit, approve, export, and delete information without hidden steps?
- Does the product make one clear recommendation instead of overwhelming the user?
- Are prototype limitations stated honestly?
- Does the interface remain usable on a narrow browser window?

## Current limitations

- Local browser storage only
- No login or cloud synchronization
- No direct resume document generation
- No job-posting import
- No email, calendar, or recruiter connectors
- No payment or membership system
- No autonomous applications or messages

These limitations are explicit and should not be represented as completed features.
